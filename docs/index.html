        Architecture

        Every signal takes the same short path.

        Plain files go in, a sealed ledger sits in the middle, and an explained incident comes out. This page runs the same steps in your browser on synthetic data.

        1. Sources

          Your files

          Relay CSV, access-control JSON or your own log.

        2. Contract

          Event contract

          One shared shape for every signal. No physical protocol is connected here.

        3. Ledger

          Sealed ledger

          Each event is chained to the one before it with SHA-256.

        4. Rules

          Correlator

          Links a denial and a held-open door within 300 s, held 120 s or longer.

        5. Output

          Control Room

          Shows the case, the rule check and the evidence. Advisory only.
