# Vendored fonts

The Control Room makes no third-party request, so the two typefaces are served from this folder.

| File | Family | Subset | License |
|---|---|---|---|
| `dm-sans-latin.woff2` | DM Sans (variable, weight 400 to 700) | Latin | SIL Open Font License 1.1 |
| `space-grotesk-latin.woff2` | Space Grotesk (variable, weight 400 to 700) | Latin | SIL Open Font License 1.1 |

Both were fetched once from the Google Fonts CDN files that the page previously requested at runtime (2026-11-11) and are redistributed unmodified under the OFL. The OFL permits bundling and redistribution with software provided the license is retained; the copyright holders are the DM Sans Project Authors and the Space Grotesk Project Authors. License text: https://openfontlicense.org/open-font-license-official-text/

Only the Latin subset is included, which covers this English interface. Characters outside it fall back to the system font.
